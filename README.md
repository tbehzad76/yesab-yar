# حساب‌یار (Hesabyar)

نرم‌افزار مدیریت مالی شخصی — بک‌اند **FastAPI** و فرانت‌اند **React (SPA)**، کاملاً داکرایز شده.

## قابلیت‌ها

- **حساب‌ها**: نقدی، بانکی، کیف پول و اعتباری با محاسبهٔ خودکار موجودی
- **تراکنش‌ها**: درآمد، هزینه و انتقال بین حساب‌ها + دسته‌بندی و فیلتر و صفحه‌بندی
- **وام و خرید قسطی**: ساخت برنامهٔ پرداخت، تولید خودکار جدول اقساط، ثبت/لغو پرداخت هر قسط
- **طلب و بدهی**: پولی که به کسی داده‌اید (طلب) یا از کسی گرفته‌اید (بدهی) + پرداخت‌های جزئی
- **اشخاص و دسته‌بندی‌ها**
- **داشبورد**: موجودی کل، درآمد/هزینهٔ ماه، تراز، اقساط پیش‌رو و نمودار هزینه بر اساس دسته
- **احراز هویت**: ثبت‌نام/ورود با JWT و پشتیبانی از چند کاربر

## معماری

```
hesabyar/
├─ docker-compose.yml      # سرویس‌های db + backend + frontend
├─ .env.example            # نمونهٔ متغیرهای محیطی (کپی کنید به .env)
├─ backend/                # FastAPI + SQLAlchemy (async) + PostgreSQL
│  └─ app/
│     ├─ core/             # config، db، security (JWT/bcrypt)
│     ├─ models/           # مدل‌های دیتابیس
│     ├─ schemas/          # اسکیمای Pydantic
│     ├─ api/routes/       # روت‌های REST
│     ├─ services/         # منطق جدول اقساط و موجودی
│     └─ main.py
└─ frontend/               # React + TypeScript + Vite (سرو با Nginx)
   └─ src/
      ├─ components/       # Layout و اجزای UI
      ├─ pages/            # صفحات
      ├─ api.ts            # کلاینت HTTP
      ├─ auth.tsx          # وضعیت ورود
      └─ types.ts
```

- فرانت‌اند روی درگاه **3000** سرو می‌شود و مسیر `/api` را به سرویس `backend` پروکسی می‌کند (بدون مشکل CORS).
- بک‌اند روی درگاه **3001** (مستندات در `/docs`).
- PostgreSQL روی درگاه **3002** (فقط روی لوکال‌هاست).

## اجرا

۱) متغیرهای محیطی را بسازید و کلید امنیتی را عوض کنید:

```bash
cp .env.example .env
# SECRET_KEY را با یک رشتهٔ تصادفی طولانی جایگزین کنید:
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

۲) سرویس‌ها را بالا بیاورید:

```bash
docker compose up -d --build
```

۳) استفاده:

- رابط کاربری: http://localhost:3000
- مستندات API: http://localhost:3001/docs

ساخت جدول‌های دیتابیس هنگام راه‌اندازی بک‌اند به‌صورت خودکار انجام می‌شود.

## توسعهٔ محلی

بک‌اند:

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate      # ویندوز
pip install -r requirements.txt
# اجرای فقط دیتابیس در داکر و بک‌اند به‌صورت محلی:
docker compose up -d db
uvicorn app.main:app --reload --port 3001
```

فرانت‌اند:

```bash
cd frontend
npm install
npm run dev        # روی http://localhost:3000 با پروکسی /api به :3001
```

## نکات

- موجودی هر حساب = موجودی اولیه + درآمد − هزینه + انتقال‌های ورودی − انتقال‌های خروجی.
- تاریخ‌ها در رابط کاربری **شمسی (جلالی)** نمایش داده می‌شوند و انتخاب تاریخ با تقویم شمسی انجام می‌شود؛ اما در API و دیتابیس تاریخ‌ها میلادی و در قالب ISO `YYYY-MM-DD` ذخیره می‌شوند.
- هنگام ساخت وام/خرید قسطی، مبلغ هر قسط به‌صورت مساوی تقسیم می‌شود و اختلاف گرد‌کردن به قسط آخر اضافه می‌گردد.
- اگر برای برنامهٔ اقساط «حساب پرداخت» انتخاب کنید، هنگام پرداخت هر قسط یک تراکنش هزینه ثبت می‌شود (قابل خاموش‌کردن).
- برای اجرای مهاجرت‌های نسخه‌بندی‌شدهٔ دیتابیس می‌توانید بعداً Alembic افزود؛ در نسخهٔ فعلی جدول‌ها با `create_all` ساخته می‌شوند.
- در هر استارت چند اصلاح سبک و idempotent روی اسکیمای موجود اجرا می‌شود (`backend/app/core/schema_fixes.py`) تا جدول‌های ساخته‌شدهٔ قبلی هم بدون حذف داده اصلاح شوند.
